# Layout & design rules (IMPORTANT)

When working on ANY page or section, always make it "screen-fit" and well-proportioned on full desktop — proper alignment, padding, text size, and image size. Sections must not overflow so that the bottom content spills onto the next scroll unnecessarily. Poorly-fitted sections look bad, so compact the vertical spacing (section padding, heading margins, card heights, image heights) until the section sits cleanly.

Reference: the HOME PAGE is the approved standard. It is already tuned and looks best. When styling any other page/section, match the home page's feel — its horizontal padding (`px-6 sm:px-10 lg:px-16`), compact vertical rhythm, heading sizes, and image sizing. Use it as the baseline for consistency across the whole site.
